# my-first-app

A simple web app to track daily expenses against your monthly income.

## Features
- Save monthly income (EUR).
- Add daily expenses with optional category and automatic expense icons (e.g., ⛽ for fuel, ☕ for coffee).
- Automatic category creation (with fallback smart category suggestion).
- Total expense, remaining balance, and over-budget calculation.
- Month-end spending prediction based on current pace.
- Avoidable cost suggestions from flagged expenses.
- Local storage persistence.

## Run locally
Open `index.html` in your browser.
